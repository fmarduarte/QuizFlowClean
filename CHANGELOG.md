# Changelog

All notable changes to QuizFlow AI are documented in this file.

## [v0.2.0] — AI Funnel Builder Positioning Update (2026-06-06)

### Highlights

- Repositioned QuizFlow as an **AI Funnel Builder** for paid social ads
- Added **4 funnel categories** on the landing page: Lead Generation, Product Recommendation, Qualification, and Application
- Updated dashboard and navigation terminology (Funnel Generator, My Funnels, Funnel Builder)
- **Phase 1 completed** — copy and positioning only; no breaking changes to core systems

### Unchanged

- Authentication and Supabase integration
- Generation engine and data storage
- Routes, file names, and database/localStorage structure
